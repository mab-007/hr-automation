# Wheel365 newspaper site

Editable React source for the root GitHub Pages landing page.

Run `npm ci` then `npm run build`. Copy `dist/index.html` to the repository root and merge `dist/assets/` into the root `assets/` folder before committing and pushing main. Keep root `CNAME` and `.nojekyll` intact.

Only the newspaper experience is included; no train or concept routes.
